Back up client data

Creates a consistent, verified SQLite snapshot while the system is running. It does not overwrite existing backups.

Start automatically

Enable this once. After the next Mac sign-in, the application starts automatically; open http://127.0.0.1:8510. This does not start before sign-in or keep the Mac awake.

Stop the application

Use this only when you want the local website to stop. All saved applications and committee decisions remain in the database.
